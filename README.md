# fuchi

Installers only. The code isn't here.

**Install:** download `fuchi-setup-<version>.exe` from [Releases](../../releases/latest) and run it. Windows 10 or 11, 64-bit. No admin needed: it installs for you alone, in `%LOCALAPPDATA%\fuchi`.

The installer isn't signed, so Windows SmartScreen may warn you: click **More info**, then **Run anyway**.

**Updates:** fuchi updates itself from here. It checks when you open it, and shows **Update** in the title bar if a new version comes out while it's open.
